# Internationalisation

* Source strings: `i18n/locales/en.ts`. `TranslationKey` is derived from it,
  so `t('student.dashbord.welcome')` (typo) fails `tsc`.
* `am.ts` is a partial Amharic bundle; missing keys fall back to English.
  **Needs review by a native-speaking educator before release.**
* Locale = user choice (Settings → Language, stored on device) or the best
  match from `expo-localization`.
* New languages without an app release: fetch a bundle from the backend
  (API GAP #9) and `registerBundle(locale, bundle)`. `isRtl()` is ready for
  right-to-left scripts.
* Tests assert every Amharic key exists in English and placeholders match.

Adding a language: copy `am.ts`, translate, add the code to
`BUNDLED_LOCALES` and `languages.*` in `en.ts`.
